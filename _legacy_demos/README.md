# Legacy demos (not runnable yet)

These examples, the README demo and the helper scripts were written for Chronicle 0.5.0. They use
APIs that no longer exist (local stores, fixtures, the CLI, the visualizer, `ReplayInjector`,
single-slot callbacks), so **they do not run against the current code**.

They are kept here, not deleted, so they can be rewritten later against a local control plane
(design section 12.1, "Local control-plane scaffold and examples rewrite").

This folder is excluded from linting, tests and packaging.
